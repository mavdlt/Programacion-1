#Programación 1

Este repositorio contiene los programas y ejercicios desarrollados durante la materia de Programación1.

Los ejercicios están organizados por temas, y cada programa se encuentra en su propia carpeta.

## Contenido

| Programa | Función |
| --- | --- |
| `Programación-1/BlackJack.py`| Simula el juego del 21 |
| `Programación-1/CifradoCesar.py` | Codifica un mensaje y lo decodifica de a cuerdo al alfabeto y un desplazamiento dado.|
| `Programación-1/CURP.py` | Obtiene los primeros 16 caracteres de la CURP |
| `Programación-1/DiasSemana.py` | Indica el día de la semana que es segun una fecha dada. |
| `Programación-1/JuegoLuces.py` | El juego consiste en apagar todas las luces en el menor numero de movimientos posibles. |

## Cómo ejecutar los programas

### CifradoCesar

codifica un mensaje y lo decodifica de a cuerdo al alfabeto y un desplazamiento dado

**Requisitos:**
- Tener instalado Python 3.

**Ubicación:** `Programación-1/CifradoCesar.py`

**Para ejecutarlo:**

Escribe un mensaje a codificar y un desplazamiento, el programa se encargará de codificarlo y decodificarlo.

```bash
Programación-1/CifradoCesar.py
```
## Ejemplo de funcionamiento

Al ejecutar `Programación-1/CifradoCesar.py`, el programa solicita un mensaje y un desplazamiento para codificar y decodificarlo


**Ejemplo de entrada y salida:**

```
Este programa encripta mensajes de acuerdo al abecedario y un desplazamiento dado. Además es capaz de desencriptar mensajes.
Escribe tu mensaje a codificar: HolaMundo
Desplazamiento = 5

Tu mensaje codificado es MupfQzsiu
Tu mensaje decodificado es HolaMundo
```
